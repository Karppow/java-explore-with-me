# Explore With Me

Explore With Me — многомодульное микросервисное приложение для публикации, поиска и управления событиями.

Проект позволяет пользователям создавать мероприятия, искать интересные события, отправлять заявки на участие и получать статистику просмотров.

## Архитектура

Проект состоит из двух независимых сервисов:

### Main Service

Основной сервис приложения.

Функциональность:

* управление пользователями;
* создание и редактирование событий;
* модерация событий администраторами;
* работа с категориями;
* создание подборок событий;
* подача заявок на участие;
* комментарии к событиям;
* получение статистики просмотров.

### Stats Service

Сервис статистики.

Функциональность:

* сбор информации о просмотрах событий;
* хранение статистики посещений;
* предоставление агрегированной статистики основному сервису.

## Архитектурная схема

```text
Client
   |
   v
Main Service
   |
   v
Stats Service

PostgreSQL      PostgreSQL
```

Каждый сервис имеет собственную базу данных и взаимодействует через REST API.

## API

Проект разделяет доступ по ролям:

### Public API

Публичный доступ к событиям и подборкам.

### Private API

Функциональность авторизованных пользователей:

* создание событий;
* управление своими мероприятиями;
* работа с заявками.

### Admin API

Административный функционал:

* модерация событий;
* управление категориями;
* управление подборками.
